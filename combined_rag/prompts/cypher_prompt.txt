## Graph Schema

### Node Types:

1. **Hazard**
   - Properties: id, name, h_type, q_source, p_init, s_init, r_init, p_final, s_final, r_final
   - p_init/p_final: Probability (1-5, higher = more frequent)
   - s_init/s_final: Severity (1-5, higher = more severe)
   - r_init/r_final: Risk level (L=Low, M=Medium, H=High)
   - Example names: "Temperature", "Low temperatures", "Power supply", "LN2 Leak"

2. **Control**
   - Properties: id, description, implementation_reference
   - id format: M1, M2, M3, etc.
   - Example: M5 = "Unit tested to IEC 61010-1 safety standard"

3. **Cause**
   - Properties: id, description
   - Triggering conditions for hazards
   - Example: "Ambient High", "Temperature sensor failure", "Mains voltage fluctuations"

4. **Consequence**
   - Properties: id, description
   - Outcomes/impacts of hazards
   - Example: "Frost burn", "Shock hazard", "Sample degradation"

5. **HazardCategory**
   - Properties: id, name
   - Example: "5 Thermal energy", "3 Electromagnetic and permanent-magnet energy"

6. **Actor**
   - Properties: name
   - Values: Product, User, Third party, Service, Environment

7. **Standard**
   - Properties: id, name
   - Example: "IEC 61010-1", "IEC 61326", "RoHS"

8. **DocumentSection**
   - Properties: id, name, document_type
   - Example: "OI Section: Maintenance", "PSS 7452-700-090"

9. **LifecyclePhase**
   - Properties: name
   - Values: Operation, Maintenance, Installation, Transport, Design, Production

### Relationships:

1. (HazardCategory)-[:CONTAINS]->(Hazard)
2. (Hazard)-[:HAS_CAUSE]->(Cause)
3. (Hazard)-[:HAS_CONSEQUENCE]->(Consequence)
4. (Hazard)-[:MITIGATED_BY]->(Control) with properties: p_reduction, s_reduction
5. (Hazard)-[:AFFECTS]->(Actor)
6. (Hazard)-[:OCCURS_DURING]->(LifecyclePhase)
7. (Control)-[:REFERENCES]->(Standard)
8. (Control)-[:DOCUMENTED_IN]->(DocumentSection)

## Query Examples

### Finding hazards by topic (ALWAYS use CONTAINS + toLower):

MATCH (h:Hazard)-[:HAS_CAUSE]->(c:Cause)
WHERE toLower(h.name) CONTAINS 'temperature' OR toLower(h.name) CONTAINS 'thermal'
RETURN h.id, h.name, c.description as cause

### Finding causes of a specific type of hazard:

MATCH (h:Hazard)-[:HAS_CAUSE]->(c:Cause)
WHERE toLower(h.name) CONTAINS 'power' OR toLower(c.description) CONTAINS 'power'
RETURN h.id, h.name, c.description as cause

### Finding hazards and their consequences:

MATCH (h:Hazard)-[:HAS_CONSEQUENCE]->(co:Consequence)
WHERE toLower(h.name) CONTAINS 'ln2' OR toLower(co.description) CONTAINS 'ln2'
RETURN h.id, h.name, co.description as consequence

### Finding controls for specific hazards:

MATCH (h:Hazard)-[:MITIGATED_BY]->(c:Control)
WHERE toLower(h.name) CONTAINS 'thermal' OR toLower(h.name) CONTAINS 'temperature'
RETURN h.id, h.name, c.id as control_id, c.description as control

### Finding controls that mitigate multiple high-severity hazards:

MATCH (h:Hazard)-[:MITIGATED_BY]->(c:Control)
WHERE h.s_init >= 4
WITH c, collect(h.id) as hazards, count(h) as cnt
WHERE cnt > 1
RETURN c.id, c.description, hazards, cnt
ORDER BY cnt DESC

### Finding hazards that remain above ALAP:

MATCH (h:Hazard)
WHERE h.r_final IN ['M', 'H']
RETURN h.id, h.name, h.r_init as initial_risk, h.r_final as final_risk, h.s_final as final_severity

### Finding hazards during specific lifecycle phases:

MATCH (h:Hazard)-[:OCCURS_DURING]->(l:LifecyclePhase)
WHERE toLower(l.name) CONTAINS 'maintenance'
RETURN h.id, h.name, l.name as phase

### Finding controls by standard:

MATCH (c:Control)-[:REFERENCES]->(s:Standard)
WHERE toLower(s.id) CONTAINS '61010'
RETURN c.id, c.description, s.id as standard

### Full hazard chain:

MATCH (hc:HazardCategory)-[:CONTAINS]->(h:Hazard)
WHERE toLower(hc.name) CONTAINS 'thermal'
OPTIONAL MATCH (h)-[:HAS_CAUSE]->(ca:Cause)
OPTIONAL MATCH (h)-[:HAS_CONSEQUENCE]->(co:Consequence)
OPTIONAL MATCH (h)-[:MITIGATED_BY]->(c:Control)
RETURN hc.name as category, h.id, h.name, ca.description as cause, co.description as consequence, collect(c.id) as controls

### Risk reduction analysis:

MATCH (h:Hazard)-[r:MITIGATED_BY]->(c:Control)
WHERE r.p_reduction IS NOT NULL OR r.s_reduction IS NOT NULL
RETURN c.id, c.description, avg(r.p_reduction) as avg_prob_reduction, avg(r.s_reduction) as avg_severity_reduction
ORDER BY avg_severity_reduction DESC
